# Открытый склад справочников

Это открытая часть рабочих материалов. Здесь лежат только справочные данные —
то, что верно для всех и не зависит от конкретной компании: составы систем,
нормы расхода, названия материалов и работ.

Склад открыт всему миру намеренно, поэтому сюда не кладётся ничего личного
и коммерческого.

## Что здесь есть

| Файл | Что внутри | Строк |
|---|---|---|
| `spravochniki/knauf-sistemy-sostav.csv` | Состав систем Кнауф на 1 м²: система, элемент, норма, единица | 148 |
| `spravochniki/raboty-k-sisteme.csv` | Соответствие вида работ и системы, с оценкой уверенности | 104 |
| `spravochniki/nomenklatura-materialov.csv` | Названия материалов по категориям и маркам, с единицами | 1114 |
| `spravochniki/normy-rashoda-materialov.md` | Нормы расхода материалов по видам работ из открытых источников | — |

Разделитель в таблицах — точка с запятой, кодировка UTF-8.

## Задания и правила

| Файл | Что внутри |
|---|---|
| `zadaniya/razrezy-otkrytye-uzly.md` | Текущее задание: закрыть 13 открытых узлов по разрезам |
| `pravila/kak-zaschityvaetsya-chertezh.md` | Когда разрез засчитан, когда нет, и в каком виде даётся ответ |
| `pravila/kak-sdavat-rezultat.md` | Результат сдаётся файлом `.md` со строкой, в какую папку его класть |

Задания лежат здесь целиком. В переписке приходит только ссылка.

## Чего здесь нет и не будет

1. Цен, скидок, отсрочек и условий договоров.
2. Названий заказчиков, объектов и юрлиц.
3. Списков поставщиков и любых данных, по которым виден круг закупок.
4. Паролей, ключей и токенов — они не кладутся ни в открытый склад, ни в закрытый.

## Как этим пользоваться

Файлы можно читать напрямую по адресу вида
`https://raw.githubusercontent.com/kostoprav2580/zarya-open/main/spravochniki/имя-файла`.

Склад только на чтение. Изменения вносит владелец.

## Оговорки к данным

1. Соответствие работ и систем размечено автоматически; колонка `confidence`
   показывает уверенность разметки, и низкие значения требуют проверки.
2. Номенклатура материалов — сырые названия из документов, не приведённые
   к единому виду: одно и то же может встречаться в разных написаниях.
3. Нормы расхода собраны из открытых справочников и требуют сверки
   с паспортом конкретного производителя.
